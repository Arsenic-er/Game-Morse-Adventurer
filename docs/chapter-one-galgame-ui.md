# 第一章 Galgame 对话界面

范围：第一章正式剧情与第一章独立故事审阅共用 `VisualNovelStage`。真实电台操作、通联判定、存档验证、章节奖励及第二至十五章的操作界面不在本次改动范围内。

## 演出

- 场景 / 剧情 CG 铺满画面，人物段使用已有肖像做柔边特写，不重新生成或改变已确认的画风与台词。
- 底部半透明对话框、旁白名牌、逐字显示，每次只读一段。现有文字属于旁白，不冒充角色台词。
- 点击对白或“继续”、空格 / Enter：先补全当前句，再显示下一句，段末才执行明确标注的剧情 / 电台 / 结算动作。
- 自动模式仅在本段内阅读，停在段末，不自动进入电台、播放审阅电报或领取奖励。减少动态效果模式直接显示全文并关闭自动阅读。
- 回看仅收录本次进入剧情后已经显示完整的句子；没有未读剧透。刷新仍按原有场景书签续读，不新增逐字存档。
- 原画、回看与任务记录使用可关闭的对话层，支持 Escape、焦点限制和返回触发按钮；隐藏界面后有恢复按钮。
- 设置、窗口失焦、页面后台、隐藏界面和对话层打开时暂停逐字 / 自动推进。室内原有远景、水面、星光、设备灯与环境音乐继续使用原来的媒体系统。
- 最终 UTC、对方呼号、RST 和频率放在“任务记录”；只显示正式保存的真实通联记录。独立审阅仍明确标注“不写入正式存档”。
