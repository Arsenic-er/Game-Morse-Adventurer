# Chapter 1–15 media implementation

Status: implemented on `agent/chapter-media`.

## Deliverable contract

Every story chapter owns exactly five runtime assets under `public/assets/chapters/NN/`:

| Asset | Runtime filename | Purpose |
| --- | --- | --- |
| Environment | `scene.png` | Chapter-specific screen backdrop and Mission Center preview |
| Character | `portrait.png` | Off-air Mission Center preview and chapter gallery |
| Story beat | `illustration.png` | Off-air chapter gallery briefing/debrief art |
| Ambience | `ambience.wav` | Low-volume, looping chapter environment |
| Music | `music.wav` | Low-volume, looping chapter score |

The catalog in `src/media/chapterMediaCatalog.js` is the single runtime mapping. Portraits and story illustrations appear only in the off-air Mission Center; on-air activity screens use the environment art and never request a character portrait. Chapter audio starts only after a trusted user interaction, pauses while the window is hidden/unfocused or Settings is open, and can be disabled or mixed separately in Settings.

## Visual direction and story beats

All visual assets are original AI-assisted work generated for this project. The common direction was cinematic, high-detail hand-painted pixel art in a restrained 1990s 32-bit adventure-game language: aged wood, deep navy shadows, brass hardware, cyan instruments, amber practical lamps, readable 16:9 staging, no logos or real-world agency marks. Scene and character references were supplied to each story illustration to maintain chapter continuity.

## Audio direction

`scripts/generate_chapter_audio.py` deterministically synthesizes all 30 original mono PCM loops at 16 kHz, 16-bit, 12 seconds. The ambience profiles are: dawn room, paper room, three receivers, rain window, memorial lights, hill wind, QSL desk, blackout net, relay grid, contest room, silent watch, coastal storm, night windows, old log, and sunrise room. Each music loop has a chapter-specific root, tempo, melody, and four-part harmonic phrase. Strong sustained energy around the game's 650 Hz CW tone is avoided.

Run `pnpm media:generate` to reproduce the WAV files. The image files are intentionally not regenerated by that command.

## Verification

`test/chapter-media.test.js` enforces:

- fifteen catalog entries and five files per entry;
- valid PNG signatures and minimum dimensions;
- valid mono 16 kHz, 16-bit RIFF/WAVE headers;
- distinct SHA-256 content for every chapter within each asset type;
- correct screen-to-chapter routing;
- bounded, versioned, failure-safe audio preference persistence.

Production build verification also retains the existing 500 KiB owned-JavaScript gate. The initial integrated build reports 490,687 bytes for the largest owned JS chunk and passes that gate.
