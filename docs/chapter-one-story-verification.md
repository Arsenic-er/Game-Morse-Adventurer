状态：第一章正式流程已实现并通过本地验收，尚未合并、推送或发布新版本。本次不扩展第二至十五章。

## 体验入口

在当前预览中从标题进入存档选择，使用新存档或尚未领取第一章奖励的存档。在管理中心点击「第一章 · 第一次开机」。任务中心已接受的第一章卡片也有入口。

流程是：接受任务 → 静默、值守、呼叫三幕 → 原有电台真实发报 → 成功后写入日志 → 回应、第一行两幕 → 领取原有任务奖励、开放第二章。

已完成第一章的旧存档不重置进度、不补发奖励。独立审阅入口 `?review=chapter-1` 保留，仍不写入正式存档。

## 实现边界

- 复用已认可的三张原画、中文叙事和章节音乐、环境效果；正式界面补全七种语言。
- 新增版本化、绑定任务接受时间的叙事书签，退出或刷新后可续读。放弃任务后重新接受，不继承旧书签。
- 实际通联仍经过原有电键、解码、呼号/RST 校验、对方回应和结算系统。未完成或未保存的通联不会触发剧情结尾。
- 结尾必须同时找到同一条正式日志、已结算 QSO ID 和第一章任务事件，展示真实对方呼号、双方 RST、频率和 UTC 时间。
- 通联收入与任务奖励仍走原有的两条结算事务。叙事不自行创建 QSO、不重复付款。
- 设置打开时正文不可交互，章节音频暂停；原图查看支持 Escape 与焦点返回。390px 窄屏可以滚动到正文和主按钮，没有页面横向溢出。

## 可复现浏览器验收

构建并启动本地预览后运行：

```powershell
corepack pnpm@10.12.1 exec vite build
node scripts/report-build-size.mjs
# 在另一个终端保持预览运行
corepack pnpm@10.12.1 exec vite preview --host 127.0.0.1 --port 4176 --strictPort
# 在项目根目录执行验收
```
