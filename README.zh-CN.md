## 游戏简介

Game-Morse-Adventurer 是一款本地运行的 Windows CW 台站模拟游戏原型。进入电台后接收机会立即开启并持续播放背景噪声；玩家使用手键或自动双桨先发送 CQ，系统再依据离线传播状况判断是否有虚构台站回应，并继续完成标准化通联。

## 主要内容

- Fusion Bold Pixel 字体与硬边深色像素界面。
- 简体中文、繁體中文、日本語、English 四语言。
- 标准莫尔斯时序、固定 650 Hz 侧音、手键 WPM 自动检测、解码与节奏评分。
- 手键使用 `Space`；自动键速度可在 5–40 WPM 调整，使用 `Z` 发点、`X` 发划，长按可连续发报。
- 独立练习台：字符、虚构呼号、手键和自动键练习。引导、标准、挑战三档难度分别设置接收速度和课程达标要求；四种模式均按课程逐课解锁。
- 确定性的 shuffled-bag 保证同一轮不重复；当前课程题库数量允许时，新一轮会避开最近 4 题。每题最多结算一次，训练总结显示本次题数、准确率、节奏、薄弱字符和课程进度。
- 已选中存档时，四种模式分别累计长期成绩、当前课程和解锁进度；练习记录 v2 会用安全默认值迁移旧存档。未选中存档时仍可完整练习，但成绩只保留在当前会话。
- Home 场景新增可交互的 `MORSE CODE` 书本入口，从管理中心进入练习后仍保持当前存档，退出时返回 Home。
- 玩家主叫的完整虚构 QSO：接收机自动监听、玩家先发 CQ、传播决定是否有人回应，再交换双方呼号、RST 与 73/SK。
- 四语言首次值守简报与“完整引导 / 仅提示 / 关闭”三档任务卡，在不提前泄露对方呼号的前提下说明当前 QSO 步骤。
- 未听清时可发送 `AGN K`，同一台站会按同一信道条件重发；格式错误会保留译码供修正，不再固定两次后强制结束。
- 通联报文按无线电语义严格校验：对方呼号、`DE`、本台呼号、`RST`、报告、`73`、`K`；顺序错误或程序信号缺失会得到对应提示，不会误判通过。
- 持久化 QSO 结果页与通联日志除记录呼号、地区、距离、RST、传播、设备与发报指标外，还会逐条复盘每次接受、错误与重发操作。
- 在关闭引导且未打开实时视觉辅助的情况下完成通联，可达成“独立值守”，在 100 基础信用点上额外获得 50 信用点。
- 四语言成就档案从持久通联统计与日志中推导六项永久里程碑，不会重复发放奖励；QSO 新解锁的成就会通过非阻断通知队列即时显示。
- 信用点采用原子化、幂等结算，同一次已完成通联不会被重复奖励。
- 首台可替换电台为虚构的 MICA-8，售价 800 信用点，参考开源 uSDX/uSDR 的 QRP 思路：5 W、八波段硬件档案、接收噪声降低 20%、AGC 使听感中的 QSB 深度降低 15%，发射时只有红色二极管点亮。当前游戏仍固定在 21.060 MHz CW。
- 单配件槽支持售价 300 信用点的 CW-500 音频滤波器：以 650 Hz 为中心、带宽 500 Hz，将接收噪声降低 35%，并把装备快照写入通联日志。
- 台站时钟同时显示所选地点的当地时间与 UTC。
- 由台站位置、UTC 和 21.060 MHz 确定生成的离线传播系统。
- 传播等级实际影响 NPC 可用性、信号增益、噪声、QSB 和轻微频偏。

## 开发

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

当前 **v0.18.0** 继续完善 CW 教学，不新增电台、天线或配件。引导、标准、挑战三档难度采用逐步提高的接收速度和达标门槛；每种练习模式从小型入门字符组开始，逐课解锁到完整题库。活动存档会通过练习记录 v2 保存各模式的难度、当前课程、课程内进度和已完成课程，旧记录会安全迁移。Home 场景新增可交互的 `MORSE CODE` 书本入口，可直接进入练习并在退出后返回管理中心。每次 `main` 更新仍会生成带 SHA-256 校验的 Windows x64 便携版。
