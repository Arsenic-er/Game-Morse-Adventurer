## 游戏简介

Game-Morse-Adventurer 是一款本地运行的 Windows CW 台站模拟游戏原型。进入电台后接收机会立即开启并持续播放背景噪声；玩家使用手键或自动双桨先发送 CQ，系统再依据离线传播状况判断是否有虚构台站回应，并继续完成标准化通联。

## 主要内容

- Fusion Bold Pixel 字体与硬边深色像素界面。
- 简体中文、繁體中文、日本語、English 四语言。
- 标准莫尔斯时序、固定 650 Hz 侧音、手键 WPM 自动检测、解码与节奏评分。
- 手键使用 `Space`；自动键速度可在 5–40 WPM 调整，使用 `Z` 发点、`X` 发划，长按可连续发报。
- 独立练习台：字符、虚构呼号、手键和自动键练习。
- 玩家主叫的完整虚构 QSO：接收机自动监听、玩家先发 CQ、传播决定是否有人回应，再交换双方呼号、RST 与 73/SK。
- 持久化 QSO 结果页与通联日志，记录呼号、地区、距离、RST、传播、设备、WPM、准确率与节奏。
- 四语言成就档案从持久通联统计与日志中推导六项永久里程碑，不会重复发放奖励。
- 信用点采用原子化、幂等结算，同一次已完成通联不会被重复奖励。
- 首台可替换电台为虚构的 MICA-8，售价 800 信用点，参考开源 uSDX/uSDR 的 QRP 思路：5 W、八波段硬件档案、接收噪声降低 20%、AGC 使听感中的 QSB 深度降低 15%，发射时只有红色二极管点亮。当前游戏仍固定在 21.060 MHz CW。
- 单配件槽支持售价 300 信用点的 CW-500 音频滤波器：以 650 Hz 为中心、带宽 500 Hz，将接收噪声降低 35%，并把装备快照写入通联日志。
- 台站时钟同时显示所选地点的当地时间与 UTC。
- 由台站位置、UTC 和 21.060 MHz 确定生成的离线传播系统。
- 传播等级实际影响 NPC 可用性、信号增益、噪声、QSB 和轻微频偏。

## 开发

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

当前 **v0.14.0** 加入首台真正可购买、可替换并影响接收听感的电台 MICA-8。玩家需在商店以 800 信用点购买，设备只送入库存，不会自动装备；随后可在仓库切换，并同步显示到管理中心与通联场景。它保持 5 W，因此不虚构额外传播等级；DSP/AGC 档案将接收噪声降低 20%、听感 QSB 深度降低 15%，并可与 CW-500 安全叠加。旧存档不会凭旧字段免费获得新电台，QSO 日志会保存当时装备的电台。两态像素贴图带有 `PWR`、`BAND`、`MODE`、`TUNE / VOL` 英文标识，发射态只点亮红色二极管。现有 91 项自动测试覆盖购买、装备、迁移、通联参数与日志快照。每次 `main` 更新都会自动测试并生成带 SHA-256 校验的 Windows x64 便携版，源码仓库不会提交 EXE 或构建目录。
