## 游戏简介

Game-Morse-Adventurer 是一款本地运行的 Windows CW 台站模拟游戏原型。进入电台后接收机会立即开启并持续播放背景噪声；玩家使用手键或自动双桨先发送 CQ，系统再依据离线传播状况判断是否有虚构台站回应，并继续完成标准化通联。

## 主要内容

- 硬边深色像素界面：英、简中、繁中、日文使用 Fusion Bold Pixel，西班牙文、德文、俄文使用 Press Start 2P。
- 简体中文、繁體中文、日本語、English、Español、Deutsch、Русский 七种语言，语言选择独立持久保存。
- 标准莫尔斯时序、固定 650 Hz 侧音、手键 WPM 自动检测、解码与节奏评分。
- 手键使用 `Space`；自动键速度可在 5–40 WPM 调整，使用 `Z` 发点、`X` 发划，长按可连续发报。
- 独立练习台：字符、虚构呼号、手键和自动键练习。引导、标准、挑战三档难度分别设置接收速度和课程达标要求；四种模式均按课程逐课解锁。
- 呼号接收提供“全部 / 日本 / 美国 / 中国 / 欧洲”5 档训练筛选。每个指定地区有 8 个游戏原创、以 `SIM` 开头的虚构目标，每课新增 2 个；它们只是练习标签，不代表真实呼号分配或真实地区前缀。
- 地区只能在当前会话尚未输入答案、产生 CW 脉冲或结算题目时切换，薄弱项专项期间始终锁定。切换地区会清空呼号接收的最近题目窗口，但不会重置长期成绩、薄弱权重、正式课程计分、解锁进度或 19 课汇总。
- 确定性的 shuffled-bag 保证同一轮不重复；当前课程题库数量允许时，新一轮会避开最近 4 题。每题最多结算一次，训练总结显示本次题数、准确率、节奏、薄弱字符和课程进度。
- 每课会明确列出本课新增内容与完整复习题池；实时掌握度卡片会说明当前计分块、达标规则、剩余题数、尚需答对题数，以及本轮是否仍可达标。
- 已选中存档时，四种模式分别累计长期成绩、当前课程和解锁进度，呼号接收还会保存地区偏好。练习记录 schema v3 会把旧存档安全迁移为“全部”，把缺失或非法地区归一化为“全部”，并按当前虚构地区题池过滤最近题目；未选中存档时仍可完整练习，但成绩只保留在当前会话。
- Home 场景新增可交互的 `MORSE CODE` 书本入口，从管理中心进入练习后仍保持当前存档，退出时返回 Home。
- Home 的 `MORSE CODE` 书本会显示四种模式共 19 课的已完成数量与百分比，并在练习返回后立即刷新。
- 练习台侧栏新增四模式课程总览，分别显示每种模式的已完成课程、总课程和百分比。当前模式存在持久薄弱项时，可开始固定 5 题的专项复习，题池在开始时锁定且只包含当前已解锁的薄弱目标。
- 薄弱项专项复习会更新长期题数、正确题数、平均表现、薄弱权重、最近题目和最后练习时间，但完全不会推进、重置或改写正式课程、课程计分块及已完成课程数。
- 专项复习中，每次答对最多消除该目标 1 点薄弱权重，答错仍会增加 1 点。多字符目标优先恢复当前权重最高的字符，权重相同时按目标内字符顺序决定。5 题题池在开始时保持锁定；权重归零的目标会从下一次专项题池退出。
- 玩家主叫的完整虚构 QSO：接收机自动监听、玩家先发 CQ、传播决定是否有人回应，再交换双方呼号、RST 与 73/SK。
- 七语言首次值守简报与“完整引导 / 仅提示 / 关闭”三档任务卡，在不提前泄露对方呼号的前提下说明当前 QSO 步骤。
- 未听清时可发送 `AGN K`，同一台站会按同一信道条件重发；格式错误会保留译码供修正，不再固定两次后强制结束。
- 通联报文按无线电语义严格校验：对方呼号、`DE`、本台呼号、`RST`、报告、`73`、`K`；顺序错误或程序信号缺失会得到对应提示，不会误判通过。
- 持久化 QSO 结果页与通联日志除记录呼号、地区、距离、RST、传播、设备与发报指标外，还会逐条复盘每次接受、已发射、错误与重发操作。
- 每次结算都会永久保存七语言奖励明细：基础通联 100、独立值守 +50、P0–P2 弱信号通联 +75、首次联系新地区 +20、刷新最远距离 +25。结果页与 Home 通联日志读取同一份 schema v6 明细；旧日志只保留原有历史合计，不追溯补发。
- 七语言成就档案从持久通联统计与日志中推导六项永久里程碑，不会重复发放奖励；QSO 新解锁的成就会通过非阻断通知队列即时显示。
- 金钱采用原子化、幂等结算，同一次已完成通联不会被重复奖励。
- 类似《坎巴拉太空计划》的台站成长将技术点与金钱分开：14 个逐步变难的通联研究项目为电台、天线、信号处理、供电和自动化五类共 28 个节点提供技术点；已实现节点解锁商店购买，后期节点可见但暂不能消耗点数。
- 首台可替换电台为虚构的 MICA-8，售价 800 金钱，参考开源 uSDX/uSDR 的 QRP 思路：5 W、八波段硬件档案、接收噪声降低 20%、AGC 使听感中的 QSB 深度降低 15%，发射时只有红色二极管点亮。当前游戏仍固定在 21.060 MHz CW。
- 单配件槽支持售价 300 金钱的 CW-500 音频滤波器：以 650 Hz 为中心、带宽 500 Hz，将接收噪声降低 35%，并把装备快照写入通联日志。
- 台站时钟同时显示所选地点的当地时间与 UTC。
- 由台站位置、UTC 和 21.060 MHz 确定生成的离线传播系统。
- 传播等级实际影响 NPC 可用性、信号增益、噪声、QSB 和轻微频偏。

## 开发

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

当前 **v0.33.0** 已把二元 CQ 格式门槛改为远台真实抄收模拟。每次实际发出的呼叫都会先与多种合法 CQ 候选比对，再综合呼号识别、程序顺序、节奏、玩家速度、传播等级与对方操作员能力判定。10 个虚构呼号已绑定 7 类试验人物，在偏好速度、抄收技术、耐心、程序严格度、反应延迟、回话长度和回问方式上均有差异。清晰电文会获得定向回应；部分抄收可能收到 `?`、`AGN?`、`QRZ?` 或 `QRS?`；能辨认出呼叫但无法抄出呼号时，对方可能转为普通 CQ，完全乱码或简洁型操作员也可能保持静默。日志 schema v6 会保存 CQ 质量、抄收分、判定结果、人物档案、对方 WPM 与回问次数。v0.25 的活动 QSO 离开保护及七语言界面继续保留。 同一套远台抄收模型现在也会评估玩家的 RST/73 回报：部分抄收会收到 `AGN? K` 或 `QRS? K`，无法抄收时仍可重发，只有被完整抄收后才会完成并结算通联。 v0.28 中，10 个虚构台站里有 5 个会按人物性格分别询问功率、地点、天气、虚构姓名或虚构年龄，其余 5 个继续使用简短流程。`AGN K` 可重听问题，`SKIP K` 或 `73 K` 可跳过；日志 schema v6 只记录问题类型、回答/跳过结果和重听次数，绝不保存回答原文。MORSE、WANG、NOVA、DIEGO 与 SORA 已完成的表情图只归档在私有素材库中；当前游戏不会随包发布、加载或在无线电通联中显示这些肖像。在回报及可选问答阶段，`QRS K`、`QRS PSE K` 或 `PSE QRS K` 会请求同一台站按同一传播条件减速重发同一电文，最低为 5 WPM，且不会改变奖励。v0.30 新增带版本号、由世界种子决定的程序化人物基础，可按需重建 JP、US、CN、DE、CH、FI 六个地区共十万名虚构操作员；存档只需保存很小的世界头信息和已遇人物的变更，每个种子下的七字符 `SIM` 呼号保证唯一，并提供 `pnpm npc:generate` 用于显式预览或流式导出。目前它尚未接入实际 QSO 选台。 v0.31 新增通联发报清空手势：连续发出 7 个同类点或划只会清空当前尚未发送的输入；6 个、点划混合或出现字符级停顿均不会触发。 v0.33.0 将词间连写、时序造成的呼号拆分以及标准 `PSE K` 结尾视为等价的有效 CQ 风格；真正的乱码仍由操作员性格与传播状况决定抄收结果。
