## ゲームについて

Game-Morse-Adventurer は、ローカルで動作する Windows 向け CW 無線局シミュレーションゲームのプロトタイプです。無線局画面に入ると受信機が自動的に開いて背景ノイズが流れ、プレイヤーが縦振り電鍵または自動パドルで先に CQ を送信します。オフライン伝搬状況に応じて架空局が応答し、その後 QSO を完成させます。

## 主な特徴

- Fusion Bold Pixel フォントを使用したダークなピクセル UI。
- English、簡体中文、繁體中文、日本語に対応。
- 標準モールス符号タイミング、固定 650 Hz サイドトーン、縦振り電鍵の WPM 自動検出、復号とリズム評価。
- 縦振り電鍵は `Space`、オートキーは 5–40 WPM に調整でき、`Z` が短点、`X` が長点。長押しで連続送信。
- 文字、架空コール、縦振り、自動パドルの独立練習モード。決定的 shuffled-bag により一巡内の重複を防ぎ、新しい巡回では直近 4 問を避け、各課題は一度だけ集計されます。
- 練習結果には今回の課題数、正確度、リズム、苦手文字を表示します。セーブを選択中なら 4 モード別の通算記録へ加算し、未選択でも練習できますが記録は現在のセッション内だけに残ります。
- 受信機の自動待受、プレイヤーからの CQ、伝搬に基づく応答判定、双方のコール、RST、73/SK を含むプレイヤー主導の架空 QSO。
- 4 言語対応の初回当直ブリーフィングと「フル / ヒント / オフ」の任務ガイド。ブラインド受信中は相手局コールを先に表示しません。
- 聞き取れない場合は `AGN K` で同じ局へ同じチャネル条件の再送を要求できます。形式エラーは復号を保持して修正でき、2 回で強制終了しません。
- QSO 電文は相手局コール、`DE`、自局コール、`RST`、レポート、`73`、`K` の無線運用上の順序で厳密に検証し、順序違いや手続き符号の欠落を誤って受理しません。
- 永続化 QSO 結果画面とログブックは基本情報と送信指標に加え、受付・エラー・再送の各操作を一行ずつレビューできます。
- ガイドをオフにし、リアルタイム視覚補助を一度も開かずに QSO を完了すると単独運用となり、基本 100 クレジットに 50 クレジットが加算されます。
- 永続 QSO 統計とログから 6 つの恒久実績を導出する 4 言語対応の実績ファイル。報酬の重複付与はなく、QSO で新たに解除した実績は操作を妨げない通知キューですぐに表示されます。
- クレジットはアトミックかつ冪等に精算され、完了済み QSO に重複報酬は発生しません。
- 初の交換可能な無線機は架空の MICA-8 です。800 クレジットで購入でき、オープンな uSDX/uSDR の QRP 発想を参考にした 5 W・8 バンドの機器プロファイル、受信ノイズ 20% 低減、AGC による体感 QSB 深度 15% 低減、送信時だけ赤色ダイオードが点灯する二状態アートを備えます。現在のゲーム運用は 21.060 MHz CW 固定です。
- 単一アクセサリースロットに、300 クレジットの CW-500 オーディオフィルターを装備可能。650 Hz 中心・500 Hz 帯域で受信ノイズを 35% 低減し、装備スナップショットを交信ログへ保存します。
- 局時計には選択地点の現地時刻と UTC を同時表示。
- 局位置、UTC、21.060 MHz から決定的に生成されるオフライン伝搬モデル。
- 伝搬レベルは NPC の出現、信号利得、ノイズ、QSB、微小周波数偏移に実際に影響。

## 開発

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

現在の **v0.17.0** は、新しい機器を追加せず、最初の永続 CW 練習成長ループを完成させます。4 つの練習モードは決定的 shuffled-bag を使用し、一巡内では課題を重複させず、新しいセッションや巡回では直近 4 問をできるだけ避け、各課題を冪等に集計します。セーブを選択中ならモード別の課題数、正確度、リズム、苦手文字、最近の課題を通算し、未選択時はセッション内だけに記録します。練習終了時には 4 言語の結果概要を表示し、QSO で新しい実績を解除するとアプリ全体の非ブロッキング通知キューですぐに知らせます。`main` 更新ごとに SHA-256 付き Windows x64 ポータブル版を生成します。
