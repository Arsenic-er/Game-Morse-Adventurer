## ゲームについて

Game-Morse-Adventurer は、ローカルで動作する Windows 向け CW 無線局シミュレーションゲームのプロトタイプです。無線局画面に入ると受信機が自動的に開いて背景ノイズが流れ、プレイヤーが縦振り電鍵または自動パドルで先に CQ を送信します。オフライン伝搬状況に応じて架空局が応答し、その後 QSO を完成させます。

## 主な特徴

- Fusion Bold Pixel フォントを使用したダークなピクセル UI。
- English、簡体中文、繁體中文、日本語に対応。
- 標準モールス符号タイミング、固定 650 Hz サイドトーン、縦振り電鍵の WPM 自動検出、復号とリズム評価。
- 縦振り電鍵は `Space`、オートキーは 5–40 WPM に調整でき、`Z` が短点、`X` が長点。長押しで連続送信。
- 文字、架空コール、縦振り、自動パドルの独立練習モード。ガイド、標準、挑戦の 3 段階が受信速度と合格条件を設定し、全モードでレッスンを順番に解放します。
- コールサイン受信には「すべて / 日本 / アメリカ / 中国 / ヨーロッパ」の 5 つの練習フィルターがあります。各指定地域にはゲーム独自の `SIM` 接頭辞付き架空目標が 8 個あり、レッスンごとに 2 個ずつ追加されます。実在のコールサイン割当や地域別プリフィックスを示すものではありません。
- 地域は現在のセッションで解答入力、CW パルス、採点済み課題のいずれも発生する前だけ変更でき、苦手項目の重点復習中は常に固定されます。地域変更時はコールサイン受信の直近課題ウィンドウを消去しますが、通算成績、苦手度、正式レッスンの採点、解放進捗、全 19 レッスン集計は維持されます。
- 決定的 shuffled-bag により一巡内の重複を防ぎ、現在のレッスンプールに十分な課題がある場合は新しい巡回で直近 4 問を避けます。各課題は一度だけ集計され、練習結果には課題数、正確度、リズム、苦手文字、レッスン進捗を表示します。
- 各レッスンは今回追加される課題と復習を含む全出題範囲を明示します。リアルタイム習熟度カードは、現在の採点ブロック、合格条件、残り問題数、必要な正解数、このブロックがまだ合格可能かを示します。
- セーブ選択中は 4 モード別の通算記録、現在レッスン、解放進捗に加え、コールサイン受信の地域設定を保存します。練習記録 schema v3 は旧セーブを「すべて」へ安全に移行し、欠損・不正な地域も「すべて」に正規化して、直近課題を選択中の架空プール内に限定します。未選択時は現在のセッション内だけに残ります。
- Home に操作可能な `MORSE CODE` 本を追加。管理センターから現在のセーブを保ったまま練習へ入り、終了後は Home に戻ります。
- Home の `MORSE CODE` 本には 4 モード全 19 レッスンの完了数と割合が表示され、練習から戻ると直ちに更新されます。
- 練習画面のサイドバーに 4 モードのカリキュラム概要を追加し、各モードの完了レッスン数、総レッスン数、割合を同時に表示します。選択中モードに永続的な苦手項目がある場合、開始時に固定した現在解放済みの苦手項目だけを出題する 5 問の重点復習を開始できます。
- 苦手項目の重点復習は通算問題数、正解数、平均成績、苦手度、直近課題、最終練習時刻を更新しますが、正式レッスン、レッスン内の採点ブロック、解放進捗、完了レッスン数を進行・初期化・変更しません。
- 重点復習では、正解ごとに対象の苦手度を最大 1 ポイント減らし、不正解では引き続き 1 ポイント増加します。複数文字の課題では現在の苦手度が最も高い文字を優先し、同点時は課題内の文字順で決定します。5 問の出題プールは開始時のまま固定され、苦手度が 0 になった対象は次回の重点復習プールから外れます。
- 受信機の自動待受、プレイヤーからの CQ、伝搬に基づく応答判定、双方のコール、RST、73/SK を含むプレイヤー主導の架空 QSO。
- 4 言語対応の初回当直ブリーフィングと「フル / ヒント / オフ」の任務ガイド。ブラインド受信中は相手局コールを先に表示しません。
- 聞き取れない場合は `AGN K` で同じ局へ同じチャネル条件の再送を要求できます。形式エラーは復号を保持して修正でき、2 回で強制終了しません。
- QSO 電文は相手局コール、`DE`、自局コール、`RST`、レポート、`73`、`K` の無線運用上の順序で厳密に検証し、順序違いや手続き符号の欠落を誤って受理しません。
- 永続化 QSO 結果画面とログブックは基本情報と送信指標に加え、受付・エラー・再送の各操作を一行ずつレビューできます。
- ガイドをオフにし、リアルタイム視覚補助を一度も開かずに QSO を完了すると単独運用となり、基本 100 クレジットに 50 クレジットが加算されます。
- 永続 QSO 統計とログから 6 つの恒久実績を導出する 4 言語対応の実績ファイル。報酬の重複付与はなく、QSO で新たに解除した実績は操作を妨げない通知キューですぐに表示されます。
- クレジットはアトミックかつ冪等に精算され、完了済み QSO に重複報酬は発生しません。
- 初の交換可能な無線機は架空の MICA-8 です。800 クレジットで購入でき、オープンな uSDX/uSDR の QRP 発想を参考にした 5 W・8 バンドの機器プロファイル、受信ノイズ 20% 低減、AGC による体感 QSB 深度 15% 低減、送信時だけ赤色ダイオードが点灯する二状態アートを備えます。現在のゲーム運用は 21.060 MHz CW 固定です。
- 単一アクセサリースロットに、300 クレジットの CW-500 オーディオフィルターを装備可能。650 Hz 中心・500 Hz 帯域で受信ノイズを 35% 低減し、装備スナップショットを交信ログへ保存します。
- 局時計には選択地点の現地時刻と UTC を同時表示。
- 局位置、UTC、21.060 MHz から決定的に生成されるオフライン伝搬モデル。
- 伝搬レベルは NPC の出現、信号利得、ノイズ、QSB、微小周波数偏移に実際に影響。

## 開発

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

現在の **v0.22.0** は、新しい無線機、アンテナ、アクセサリーを追加せず、架空コールサイン受信に 5 つの地域フィルターを追加します。「すべて」は従来の 8 問を維持し、日本、アメリカ、中国、ヨーロッパにはそれぞれ 8 個の一意な `SIM` 架空目標があり、4 レッスンで 2/4/6/8 個を順に解放します。shuffled-bag、直近 4 問の回避、重点復習は、選択地域で現在解放済みのプール内だけで動作します。練習記録 schema v3 は旧セーブを「すべて」へ移行し、再読み込み後に地域、記録、一致するプールを復元します。地域変更時はコールサイン受信の直近課題ウィンドウ全体を消去しますが、通算成績、苦手度、正式レッスンの採点、解放進捗、全 19 レッスン集計は維持します。`main` 更新ごとに SHA-256 付き Windows x64 ポータブル版を生成します。
