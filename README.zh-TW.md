## 遊戲簡介

Game-Morse-Adventurer 是一款在本機執行的 Windows CW 臺站模擬遊戲原型。進入電臺後接收機會立即開啟並持續播放背景雜訊；玩家使用手鍵或自動雙槳先發送 CQ，系統再依離線傳播狀況判斷是否有虛構電臺回應，並繼續完成標準化通聯。

## 主要內容

- Fusion Bold Pixel 字體與硬邊深色像素介面。
- 簡體中文、繁體中文、日本語、English 四種語言。
- 標準摩斯時序、固定 650 Hz 側音、手鍵 WPM 自動偵測、解碼與節奏評分。
- 手鍵使用 `Space`；自動鍵速度可在 5–40 WPM 調整，使用 `Z` 發點、`X` 發劃，長按可連續發報。
- 獨立練習臺：字元、虛構呼號、手鍵與自動鍵練習。
- 玩家主叫的完整虛構 QSO：接收機自動監聽、玩家先發 CQ、傳播決定是否有人回應，再交換雙方呼號、RST 與 73/SK。
- 持久化 QSO 結果頁與通聯日誌，記錄呼號、地區、距離、RST、傳播、設備、WPM、準確率與節奏。
- 四語言成就檔案從持久通聯統計與日誌推導六項永久里程碑，不會重複發放獎勵。
- 信用點採用原子化、冪等結算，同一次已完成通聯不會被重複獎勵。
- 首臺可替換電臺是虛構的 MICA-8，售價 800 信用點，參考開源 uSDX/uSDR 的 QRP 概念：5 W、八波段硬體檔案、接收雜訊降低 20%、AGC 讓聽感中的 QSB 深度降低 15%，發射時只有紅色二極體亮起。目前遊戲仍固定於 21.060 MHz CW。
- 單配件槽支援售價 300 信用點的 CW-500 音訊濾波器：以 650 Hz 為中心、頻寬 500 Hz，將接收雜訊降低 35%，並把裝備快照寫入通聯日誌。
- 電臺時鐘同時顯示所選地點的當地時間與 UTC。
- 由臺站位置、UTC 與 21.060 MHz 決定的離線傳播系統。
- 傳播等級實際影響 NPC 可用性、訊號增益、雜訊、QSB 與輕微頻偏。

## 開發

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

目前 **v0.14.0** 加入首臺真正可購買、可替換並影響接收聽感的電臺 MICA-8。玩家須在商店以 800 信用點購買，設備只送入庫存、不會自動裝備；之後可在倉庫切換，並同步顯示於管理中心與通聯場景。它維持 5 W，因此不虛構額外傳播等級；DSP/AGC 檔案將接收雜訊降低 20%、聽感 QSB 深度降低 15%，並可與 CW-500 安全疊加。舊存檔不會因舊欄位免費取得新電臺，QSO 日誌會保存當時裝備的電臺。兩態像素貼圖帶有 `PWR`、`BAND`、`MODE`、`TUNE / VOL` 英文標示，發射態只點亮紅色二極體。現有 91 項自動測試涵蓋購買、裝備、遷移、通聯參數與日誌快照。每次 `main` 更新都會自動測試並產生附 SHA-256 校驗的 Windows x64 可攜版，原始碼倉庫不提交 EXE 或建置目錄。
