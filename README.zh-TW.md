## 遊戲簡介

Game-Morse-Adventurer 是一款在本機執行的 Windows CW 臺站模擬遊戲原型。進入電臺後接收機會立即開啟並持續播放背景雜訊；玩家使用手鍵或自動雙槳先發送 CQ，系統再依離線傳播狀況判斷是否有虛構電臺回應，並繼續完成標準化通聯。

## 主要內容

- Fusion Bold Pixel 字體與硬邊深色像素介面。
- 簡體中文、繁體中文、日本語、English 四種語言。
- 標準摩斯時序、固定 650 Hz 側音、手鍵 WPM 自動偵測、解碼與節奏評分。
- 手鍵使用 `Space`；自動鍵速度可在 5–40 WPM 調整，使用 `Z` 發點、`X` 發劃，長按可連續發報。
- 獨立練習臺：字元、虛構呼號、手鍵與自動鍵練習。引導、標準、挑戰三檔難度分別設定接收速度與課程達標要求；四種模式皆按課程逐課解鎖。
- 確定性的 shuffled-bag 保證同一輪不重複；目前課程題庫數量允許時，新一輪會避開最近 4 題。每題最多結算一次，訓練總結顯示本次題數、準確率、節奏、薄弱字元與課程進度。
- 每課會明確列出本課新增內容與完整複習題庫；即時掌握度卡片會說明目前計分區塊、達標規則、剩餘題數、尚需答對題數，以及本輪是否仍可達標。
- 已選取存檔時，四種模式分別累計長期成績、目前課程與解鎖進度；練習記錄 v2 會以安全預設值遷移舊存檔。未選取存檔時仍可完整練習，但成績只保留於目前工作階段。
- Home 場景新增可互動的 `MORSE CODE` 書本入口，從管理中心進入練習後仍保留目前存檔，離開時返回 Home。
- Home 的 `MORSE CODE` 書本會顯示四種模式共 19 課的已完成數量與百分比，並在練習返回後立即更新。
- 練習臺側欄新增四模式課程總覽，分別顯示每種模式的已完成課程、總課程與百分比。目前模式存在持久薄弱項時，可開始固定 5 題的專項複習，題庫在開始時鎖定且只包含目前已解鎖的薄弱目標。
- 薄弱項專項複習會更新長期題數、正確題數、平均表現、薄弱權重、最近題目及最後練習時間，但完全不會推進、重設或改寫正式課程、課程計分區塊及已完成課程數。
- 專項複習中，每次答對最多消除該目標 1 點薄弱權重，答錯仍會增加 1 點。多字元目標優先恢復目前權重最高的字元，權重相同時依目標內字元順序決定。5 題題庫在開始時保持鎖定；權重歸零的目標會從下一次專項題庫退出。
- 玩家主叫的完整虛構 QSO：接收機自動監聽、玩家先發 CQ、傳播決定是否有人回應，再交換雙方呼號、RST 與 73/SK。
- 四語言首次值守簡報與「完整引導 / 僅提示 / 關閉」三檔任務卡，在不提前洩露對方呼號的前提下說明目前 QSO 步驟。
- 未聽清時可發送 `AGN K`，同一臺站會按同一信道條件重發；格式錯誤會保留解碼供修正，不再固定兩次後強制結束。
- 通聯報文按無線電語義嚴格驗證：對方呼號、`DE`、本臺呼號、`RST`、報告、`73`、`K`；順序錯誤或程序信號缺失會得到對應提示，不會誤判通過。
- 持久化 QSO 結果頁與通聯日誌除記錄呼號、地區、距離、RST、傳播、設備與發報指標外，也會逐條複盤每次接受、錯誤與重發操作。
- 在關閉引導且未開啟即時視覺輔助的情況下完成通聯，可達成「獨立值守」，在 100 基礎信用點上額外獲得 50 信用點。
- 四語言成就檔案從持久通聯統計與日誌推導六項永久里程碑，不會重複發放獎勵；QSO 新解鎖的成就會透過非阻斷通知佇列即時顯示。
- 信用點採用原子化、冪等結算，同一次已完成通聯不會被重複獎勵。
- 首臺可替換電臺是虛構的 MICA-8，售價 800 信用點，參考開源 uSDX/uSDR 的 QRP 概念：5 W、八波段硬體檔案、接收雜訊降低 20%、AGC 讓聽感中的 QSB 深度降低 15%，發射時只有紅色二極體亮起。目前遊戲仍固定於 21.060 MHz CW。
- 單配件槽支援售價 300 信用點的 CW-500 音訊濾波器：以 650 Hz 為中心、頻寬 500 Hz，將接收雜訊降低 35%，並把裝備快照寫入通聯日誌。
- 電臺時鐘同時顯示所選地點的當地時間與 UTC。
- 由臺站位置、UTC 與 21.060 MHz 決定的離線傳播系統。
- 傳播等級實際影響 NPC 可用性、訊號增益、雜訊、QSB 與輕微頻偏。

## 開發

```bash
pnpm install
pnpm test
pnpm run dev
pnpm run desktop:build
```

目前 **v0.21.0** 加入可恢復的薄弱權重，不新增電臺、天線或配件。專項答對時最多消除 1 點權重，答錯仍會增加權重，多字元目標會依目前最高權重及字元順序決定恢復對象；固定 5 題的題庫不會在中途改變。專項總結會顯示恢復點數、剩餘薄弱權重及是否完全掌握；相關權重全部歸零後，專項入口會立即不可用並清空目標，重新載入後仍保持清除狀態。長期統計繼續更新，但正式課程、課程計分區塊、解鎖進度、已完成課程及 19 課總覽完全隔離，繼續使用練習記錄 v2 持久化。每次 `main` 更新仍會產生附 SHA-256 校驗的 Windows x64 可攜版。
